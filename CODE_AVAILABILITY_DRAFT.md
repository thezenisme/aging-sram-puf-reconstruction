# Code Availability

The minimal simulation, matrix-search, leakage-analysis, and FPGA scaling-core
artifacts accompanying the manuscript are publicly available at:

https://github.com/thezenisme/aging-sram-puf-reconstruction

Third-party SRAM-PUF readouts are not redistributed and must be obtained from
their original public source. The hardware artifact contains the folded decoder
scaling core, not a complete SoC, SRAM interface, helper-data store, or KDF.
