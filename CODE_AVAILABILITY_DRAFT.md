# Code Availability Statement (Draft)

The source code required to reproduce the principal simulation, spatial-error
analysis, conditional helper-data leakage check, and FPGA scaling-core results
will be made available in a public archival repository upon acceptance. The
artifact includes the fixed parity-check matrices and reliability profiles used
in the reported experiments, together with smoke-test configurations and
processed reference outputs. Third-party SRAM-PUF readouts are not
redistributed; they must be obtained from the original public source and can be
processed using the supplied import scripts. The hardware artifact contains the
folded decoder scaling core and synthesis constraints, not a complete SoC,
external SRAM interface, nonvolatile helper-data store, or KDF implementation.

Replace "upon acceptance" with a repository URL and archived DOI before final
publication whenever anonymous-review policy permits.
